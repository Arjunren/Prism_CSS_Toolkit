# Prism_CSS_Toolkit
Prism is a premium, open-source CSS dashboard for modern devs. It features 14+ interactive tools like dynamic Grid/Flex builders, Glassmorphism, Neumorphism, Keyframe Animations, and Google Font integration. Built with Tailwind CSS, it offers instant live previews and one-click CSS copying. Optimized for mobile and performance.

# 💎 Prism CSS Toolkit

**Prism** is a high-performance, premium CSS generator dashboard designed to streamline the front-end styling workflow. Built for developers by a developer, it eliminates the guesswork of modern CSS by providing real-time visual feedback and production-ready code.

## 🚀 Key Features

Prism includes **14+ specialized tools** to handle almost any design requirement:

*   **Layout Engines:** Dynamic **Grid** and **Flexbox** generators where you can add/remove boxes and resize them live.
*   **Modern Aesthetics:** Sleek **Glassmorphism**, **Neumorphism**, and **Organic Shape** (Blob) generators.
*   **Design Fundamentals:** **Color Theory** orchestrator, **Box Shadows**, and **Linear Gradients**.
*   **Typography:** A robust **Google Fonts** integrator and a precise **PX to REM** converter.
*   **Interactivity:** Designers for **Keyframe Animations**, **CSS Filters**, and **2D Transforms**.
*   **State Management:** Specialized tool for designing `:hover`, `:focus`, and `:active` transitions.

## 🛠️ Built With

- **HTML5:** Semantic structure using native `<dialog>` elements for premium modals.
- **Tailwind CSS:** For a responsive, dark-themed, and modern dashboard UI.
- **Vanilla JavaScript:** Fast, dependency-free logic for live previews and clipboard management.

## 📱 Mobile First

Prism is fully responsive. It features a smooth, slide-out sidebar menu and optimized touch controls, allowing you to generate CSS on the go from your tablet or smartphone.
